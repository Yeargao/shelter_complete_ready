# 收容所助理使用者情境驗收

管理者與照護人員可以詢問動物生病/受傷的處理步驟、回報及後續任務；回答依照角色權限及已登錄資料。導覽連結和建議指令只會開啟頁面或送出下一輪訊息，不直接寫入資料庫。醫療診斷與用藥交由獸醫。員工若沒有指派的任務仍應立即通知主管。

管理者可查庫存、疫苗到期、動物待辦，並建立健康登錄或任務草案；員工可查自己獲授權的任務，生病、受傷、失敗及追蹤回報若缺備註，助理會要求補上，仍需確認。實際派工、結案、離所、重新入所及附照片的回報仍用原本頁面與驗證。
