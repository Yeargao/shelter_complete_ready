# 智慧工作流程

## 功能入口

| 位置 | 功能 |
|---|---|
| 收容所助理 | 多意圖、多輪對話、操作捷徑、報表、建立提醒／工作流程／任務草案 |
| 總覽 | 智慧提醒與規則、AI 使用量 |
| 新增動物／動物詳細資料 | 照片比對、建檔驗證 |
| 動物詳細資料 | 個體照護流程建議、資料一致性核對 |
| 健康行政核對 | 健康、疫苗、驅蟲及資料一致性核對 |
| 資源配置 | 自動化工作流程與草案、資源及排程核對、員工交接 |
| 照護人員工作台 | 個人交接、照護摘要 |

一般聊天仍是既有受權限限制的查詢，可處理有限的本機語法；管理者可以建立任務、提醒及工作流程草案並確認。跨功能使用分號。不支援的指令會要求補充，沒有任意 SQL 或 LLM 自行寫入資料庫。

例如：
- 查詢 Rufus 的健康和疫苗紀錄；幫他安排明天的健康問題追蹤任務
- 飼料低於30公斤提醒我
- 統計這週各員工的任務完成率
- 建立工作流程，動物入所後確認疫苗紀錄及確認驅蟲紀錄

展開狀態、對話、已完成結果儲存在同一瀏覽器登入階段，登出時清除。按下重新整理才重新計算摘要／報表／掃描。即時提醒和既有班表仍按需更新。工作流程與提醒規則及確認狀態由 SQLite 保存。工作流程不自動指派員工，確認建立任務後使用原本的排程預覽。

總覽或資源配置開啟時，每 60 秒檢查提醒／工作流程；離線可在具有同一持久 DB 的後端主機設定 cron 或 Windows Task Scheduler：
```sh
cd backend
python smart_monitor.py
```
這是站內提醒，不是外部推播；未自動部署離線排程。

測試：
```sh
cd backend
python -m unittest test_smart_tools -v
cd ../frontend
npm ci
npm run build
npm test
```

照片與資料品質模型的選用設定見 [README_AI_TOOLS.md](README_AI_TOOLS.md)。
