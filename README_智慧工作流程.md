# 智慧工作流程（管理者）

在「AI 智慧工具 → 智慧工作流程」使用十項功能。一般聊天的唯讀多意圖查詢與既有簽章上下文適用所有已授權角色；管理者工作台可提出任務、提醒草案並明確確認。支援有限的本機自然語言文法，跨功能使用分號；未支援或歧義指令要求補充，不執行任意 SQL。新增功能不使用預測模型；一般聊天仍沿用既有受限 Gemini fallback。

報表、核對及交接使用既有 SQLite 實際資料。切換工具、切換頁面、同一登入工作階段重新整理時，保存已完成結果與輸入；明確重新產生、清除或登出才重設。提醒與工作流程規則持久化至 DB。開啟 AI 工具頁面每 60 秒檢查提醒；離線時可在具有同一持久 DB 的後端主機以 cron/Windows Task Scheduler 每分鐘執行：
```
cd backend
python smart_monitor.py
```
不需要 Gemini 呼叫。站內提醒不是外部推播；部署方須自行設定上述排程，未自動部署 cron。工作流程處理建立後的新事件，先產生草案，確認時重新核對動物、任務與重複狀態，不自動指派員工。既有排程預覽與套用方式維持不變。

測試：
```
cd backend
python -m unittest test_smart_tools -v
cd ../frontend
npm ci
npm run build
npm test
```
